# Ham ekran görüntüleri

Telefondan çektiğin beş görüntü buraya `1.png` … `5.png` olarak gelir.
`python tools/make_store_screenshots.py` bunları mağaza boyutuna çevirir.

Bu klasör bilerek boş — buradaki dosyalar uygulamanın gerçek yakalamaları olmak
zorunda. Uydurulmuş arayüz hem sahte durur hem App Review'ın kontrol ettiği şeydir.
